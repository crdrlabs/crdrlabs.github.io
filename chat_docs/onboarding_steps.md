# Creative Drive Labs On-boarding

To get full access to our community, follow these steps:

1. **Read the rules** in #general-rules and make sure you agree to them--you must accept our Code of Conduct. **__This is mandatory.__**
2. **Review the usage tips** in #general-usage-tips for hints on using this server effectively.
3. **Request verification** by sending a message to @verifier or showing up at the facility.  We have a policy that all approved participants must be verified as real humans.

Once verified, you'll have access to all community channels, projects, and events!

**Questions?** Feel free to message the director, consult the [web page](https://www.crdrlabs.org/), or use the web-based contact form.
