# Creative Drive Labs Chat HOWTO

## Notification

### Suggested setup

The server default notification setting is `Mentions`.

It's up to you override, per server, category, or channel.

We recommend:

* **default** : `Mentions`
* specific **topic** channels that you like: maybe `All`
* **announcements** : `All`
* **-venting** channels : `None`
* `community-made-something` : `All` -- to partake in the joy!

Admins: `All` for `team-moderators` channel.

### Inbox

Discord Inbox/Unreads sequential feed is handy for catching up periodically.

## Categories

### Public

* **General** : Basic info, rules, onboarding steps, big announcements

### Approved participants

* **Community** : chat, help, events, buy/sell/trade, updates
* **Topic** : specific curated topics like 3D printing
* **Facility** : discussions about facility details

### Limited audience

* **Team** : Moderation, security, strategy, board of directors stuff
* **Projects** : Major projects of the org

## Posting

### Basics

Use `shift-enter` to separate paragraphs.

You can use double bars to bracket spoiler alerts etc:

```
CW: scary ||Text to hide...||
```

### Formatting options

Discord allows [Markdown](https://support.discord.com/hc/en-us/articles/210298617-Markdown-Text-101-Chat-Formatting-Bold-Italic-Underline) format.

```
# Heading
## Subheading
Fancy **bold**, *italic*, __underline__, and ~~strikethrough~~ text.
* bulleted lists
> Block quoted text
[Fancy link](https://long)
```

### Forward

Have something relevant to two different channels?

Post first in the most specific one first, then create a "Forward" to the other channel.  We do this for instance to forward summaries of work-completed to the `community-made-something` channel.

## Voice and video chats

We have pre-made A/V channels `community-meetingroom` and `team-meetingroom` for use from the physical meeting room. If you're not in the physical meeting room, use something different.
